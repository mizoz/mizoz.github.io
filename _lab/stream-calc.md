"How much internet do we need?" is the first question at every live event. This answers it per platform, using each platform's own published numbers.

## Details
- YouTube, Facebook, Twitch, LinkedIn Live, Vimeo, Teams and Zoom, at the resolutions and codecs each one accepts.
- Upload bandwidth with real headroom, plus totals for streaming to several places at once.
- Matching OBS and vMix settings.
- File size for recordings, storage for a full event day with backups, and upload time.
