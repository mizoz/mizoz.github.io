When a link shares with the wrong image or a cut-off title, it's almost always the meta tags. Paste a page and this shows how it will look on Google, LinkedIn, Facebook, X, Slack, Discord, iMessage and WhatsApp, then tells you what to fix.

## Details
- Checks image size and ratio, missing tags, duplicates and relative URLs.
- A generator mode that writes the tags for you.
- Links to each platform's own debugger for clearing old previews.
